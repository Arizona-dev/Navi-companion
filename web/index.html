LE FIL DE TON AVENTURE

Ton carnet de quêtes

Un parcours conseillé pour l’histoire, avec les détours utiles. Certains temples peuvent être faits dans un autre ordre.

    Les pastilles se synchronisent avec les étapes des quêtes, les objets et les chants identifiés. Le direct est actif avec Dernière sauvegarde. Les cases cochées à la main sont conservées dans ce navigateur pour le slot sélectionné ; elles ne modifient pas le jeu.

    Parcours : guide du remake · Zelda Dungeon. Ce carnet est un guide de progression, pas le journal officiel du jeu.

    Choisir la taille de l’interface

    Mini-carte sur le jeu

    Une fenêtre flottante garde la carte visible pendant que tu joues. Le suivi, la direction de Link et les étages continuent à s’actualiser.

    Déplace la fenêtre par sa fine poignée dorée en haut et redimensionne-la par les bords. Ctrl + Alt + N verrouille les clics pour les laisser passer au jeu ; Ctrl + Alt + M masque ou réaffiche la carte.
